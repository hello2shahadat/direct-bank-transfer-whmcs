Description:
This is a manual bank transfer payment gateway for WHMCS invoices.

How it works:
1. Customer clicks Pay with Bank Transfer.
2. Bank details open in a compact popup.
3. Customer enters name, transaction reference number, sender bank/account details, and paid amount.
4. Customer submits payment details through WHMCS support ticket or email.
5. Admin manually verifies payment and marks invoice as paid.

Required WHMCS Setting:
Support Department ID must be set correctly.

Example:
Support Department ID: 1

Note:
This gateway does not automatically mark invoices as paid.
